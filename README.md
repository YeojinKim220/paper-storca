# stORCA Manuscript Repository

Canonical three-tier Markdown repository for the stORCA manuscript:

- `main/` — Main manuscript sections (`Results`, `Methods`).
- `supp/` — Supplementary Methods & Notes.
- `internal/` — Internal working notes, outlines, figure plans, and Q1–Q5 analysis reports (excluded from co-author default exports).
- `figures/` — Publication figure PNG/PDF assets referenced by `paper.json`.

Synced with [Paper Studio](../paper-studio) via GitHub Actions (`.github/workflows/sync-paper.yml`) or `paper-sync`.
